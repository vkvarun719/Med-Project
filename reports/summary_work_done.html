2. Core Engineering Deliverables by Subsystem

A. Raspberry Pi IoT Station (/automation) — The Physical Heart

  • Sensors: Modular drivers for HX711 24-bit ADC Load Cells (Weight) and HC-SR04 Ultrasonic (Height).
  • Simulation Mode: Run python main.py --mock on any laptop without hardware to test state transitions.
  • Stability Filter: Rolling-window algorithm requiring N=5 consecutive samples within configurable tolerances (±0.2 kg, ±0.5 cm). Automatically clears if a patient steps off early.
  • Wi-Fi Resilience: If clinic internet drops, readings are stored in local SQLite (buffer.db). A background worker syncs pending readings via exponential backoff upon reconnection.
  • Finite State Machine: IDLE → SCANNED → MEASURING → STABLE → SENT → RESET.
  • Boot Service: Production Linux systemd service (clinic-station.service) with crash auto-restart.

B. Cloud Backend & Database (/backend)

  • FastAPI Microservice: Strict Pydantic v2 input validation (1.0–350.0 kg, 30.0–250.0 cm) and X-API-Key station auth.
  • Automatic BMI Engine: Computes BMI = weight(kg) / (height(m)^2) on every measurement submission.
  • Neon Cloud PostgreSQL: Relational schema with patients and measurements tables (with timestamps and cascade delete).
  • Collision-Safe Barcodes: Generates unique 8-character Code128 barcodes with database collision verification.
  • Zero Secrets in Code: All connection strings and keys load cleanly from .env.

C. React Clinical Dashboard (/frontend)

  • Patient Registration: Clean form capturing Name, Age, Gender, and Phone.
  • Thermal Printable Cards: Formatted patient badge with embedded barcode graphic and print button (window.print()).
  • Station Monitor: Real-time status gauge showing live weight, height, and stability state without UI freezing.
  • Analytics & History: Multi-metric Chart.js graphs (Weight, Height, BMI trends) and clinical BMI badges (Underweight, Normal, Overweight, Obese).

5. Quickstart & Demonstration Commands

  • Run Backend: cd backend && uvicorn app.main:app --reload --port 8000
  • Run Frontend: cd frontend && npm start (Available at http://localhost:3000)
  • Run Pi Station (Mock Mode on PC): cd automation && python main.py --mock
  • Deploy with Docker: docker-compose up -d --build (Single command for EC2)
  • Run Tests: pytest tests -v
